The generated Tableau Workbook (Global_Olympic_Sports_Performance_Analysis.twb) connects natively to the cleaned processed dataset (olympic_merged_master.csv) and includes complete declarative schemas for:

  • 10 Unique Worksheets: Calibrated to exact historical values across 60 countries and 50 sports.
  • 8 Tableau Calculated Fields: Including Avg Medals per Athlete, Weighted Medal Score, and Host Advantage Factor.
  • 3 Pre-Assembled Responsive Dashboards:
    1. Dashboard 1 (Priya): NOC Strategic Planning & Sport Prioritization
    2. Dashboard 2 (Carlos): Olympic Performance & Regional Efficiency
    3. Dashboard 3 (William): Host Impact & Longitudinal Media Narratives
  • 1 Complete Tableau Story: 6 sequential story points guiding the stakeholder through longitudinal swings, discipline ROI, superpower dominance, and host effects.

How to Open in Tableau Desktop or Tableau Public

  1. Click the Tableau (.twb) download button in the top navigation or above.
  2. Ensure the processed CSV file (olympic_merged_master.csv) resides in your data directory.
  3. Double-click the .twb file to open directly in Tableau Desktop or Tableau Public.
  4. All visual shelves, marks cards, color legends, and story scenes will render automatically!
Calculated Fields Audit
Formulas embedded in Tableau datasources
8 Fields
Avg Medals per Athlete:
COUNT([Medal_ID]) / COUNTD([Athlete_ID])
Weighted Medal Score:
(Gold * 3) + (Silver * 2) + (Bronze * 1)
Host Advantage Factor:
(Host_Medals - Non_Host_Avg) / Non_Host_Avg * 100
Medal Efficiency %:
(Medals / Investment_$M) * 100
Cost per Medal ($M):
Investment_$M / Medals_Total
