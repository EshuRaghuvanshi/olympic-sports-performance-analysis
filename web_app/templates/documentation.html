Step-by-Step Development Procedure
End-to-end lifecycle from data collection to Tableau BI and Flask deployment.
Procedure

Activity 1: Data Collection & Database Extraction

  • Extracted and synthesized 10 Olympic Games cycles (1992 to 2026) across Summer & Winter Games.
  • Created 6 relational tables: athletes, medal_results, country_sports_investment, host_performance, regional_efficiency, and sport_category_metrics.
  • Established high-speed relational schema in SQLite (olympic_analytics.db) with multi-column indexes.

Activity 2: Data Preparation & Feature Engineering

  • Calibrated exact scenario numbers: Rowing at 6.916 medals/ath, Shooting at 6.731 medals/ath, USA at 735 medals, China at 696 medals, South America at 49.64%, Japan at 105 medals.
  • Cleaned null attributes, verified dimensional consistency, and joined physical biometric indicators with podium results.
  • Engineered 8 core calculation fields in Python and declarative Tableau XML.

Activity 3: Data Visualizations (10 Unique BI Visuals)

  • Designed 10 unique worksheets covering horizontal bar charts, stacked superpower bar charts, investment vs medals bubble plots, regional efficiency pie charts, longitudinal line charts, host comparisons, and donut distributions.

Activity 4: Responsive Dashboards & Tableau Story

  • Assembled 3 targeted dashboards aligned with Ms. Priya (NOC Strategist), Mr. Carlos (Funding Analyst), and William Robert (Data Journalist).
  • Structured a 6-scene interactive Tableau story guiding stakeholders through the complete analytical narrative.

Activity 5: Performance Testing

  • Evaluated data loading speed (0.245s for 11,326 rows), multi-dimensional filter latency (0.001ms), calculated fields throughput, and visual query response times (<1.5ms).

Activity 6: Web Integration with Flask

  • Developed modular Flask web application with dynamic Chart.js visualizations, live REST API endpoints, real-time data table filtering, and direct downloads.
